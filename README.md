# Hanzi Catalogue

A catalogue of nearly 10,000 Chinese characters with interactive writing animations. The data is from a _makemeahanzi_, a data set containing information such as definition, pronounciation, and writing animations for an extensive list of Chinese characters. This website was made for the Snap Engineering Academy Project Assessment.


## 🛠️ Features

1. Filtering:
   - You can filter the characters to show most commonly used characters, characters with largest number of writing strokes, and characters with the least number of writing strokes.

3. Searching:
   * You can search for specific characters by entering the pinyin(pronounciation), or by entering the unicode glyph in the search bar.
   * Example: 水 (water) has the pinyin "shuǐ". Search for it by typing "shui" or searching for the glyph.
   * Example: 你 (you) has the pinyin "nǐ". Search for it by typing "ni" or searching for the glyph.

3. Pop up info:
   - Hover over any of the characters items, and a pop up box will appear detailing: the definition, pronounciation, number of strokes required to write it, and a video showing the correct stroke order.
